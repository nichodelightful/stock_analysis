## 🎯 TL;DR

1. **三家都「優於自己的指引」,股價卻都下跌——市場在買的是下一季指引與現金流,不是本季。** Amazon 營業利益 $280.8 億超過自家指引上緣($265 億),盤後 −7%;Intel Q3 EPS $0.52 對共識 $0.41,盤後 **−23%**;SanDisk 營收 $110.3 億、EPS $49.51 皆優於共識與指引上限,盤後 −3.8%(10/29 正常盤已先跌 −5.3%)。
2. **Amazon:AWS 需求超預期(+39%、backlog $578B),代價是現金。** AWS 營收 $459.8 億(+39%,連六季加速)、營業利益率 38.7%;**但 Q3 capex $772.6 億(預期 $587 億)、單季 FCF 約 −$335 億、TTM FCF −$424 億、長期債務 $1,731 億(2025 年底 $656 億)、利息費用 $16.9 億(去年 $5.4 億),EPS $1.89 對 $1.96~1.97**。Jassy:AWS 2027 與 2028 年成長 >40%。Anthropic 不在本季損益,可轉債重估走 OCI(稅前約 $482 億,推算)。
3. **Intel:Q3 是「三年來最好的一季」,Q4 指引卻是懸崖。** 營收 $165.1 億(+20.9%)、毛利率 44.1%、DCAI $73.2 億(+78%、營業利益率 41.5%)、Foundry 營業損失率由 −54.8% 收窄到 −27.7%;**Q4 營收指引 $150–160 億(共識 $170.7 億,−9%)、毛利率 38.0%(共識 42.8%)、EPS $0.25(共識 $0.43~0.44)**。原因:PC 修正加速(客戶端 Q4 季減 >20%)、**記憶體漲價壓縮 PC 預算**、基板/Intel 3 供給受限、以色列 Fab 28 爆炸(Q4 營收 −$3 億、毛利率 −200bp)。
4. **SanDisk:AI 把 NAND 變成「現金牛」,但成長與毛利率已趨平。** 營收 $110.3 億(+378% YoY、+23% QoQ),**非 GAAP 毛利率 85.1%(上季 84.6%)、營業利益率 80.4%、營運現金流 $63.6 億**;資料中心 $48.0 億(+61% QoQ,占 43.5%),**Consumer −29% QoQ**;FQ2 指引營收 $122–126 億(中點 +12% QoQ)、毛利率 84.5–85.5%;8 換 1 分割(11/20 起以分割後價格交易)、單季回購 $50 億;無負債。**估值僅約 5.9x 前瞻 P/E(以 FQ2 中點年化,推算)——市場把 85% 毛利率視為周期頂部。**
5. **三者交叉:記憶體漲價是 SanDisk 的利潤,卻是 Intel/PC 的成本。** Intel 明言「2027 記憶體供給與價格不會改善、2028 才看是否好轉」、PC TAM 2026 約 −12%、2027 約 −10%;SanDisk 則在指引中納入「小幅 like-for-like 漲價」。**AI 資本支出(Amazon 2026 約 $2,200 億、2027 更多)把記憶體與先進封裝/基板供給吃緊,對 AI 供應鏈是順風,對 PC/消費性電子是逆風。** 10/30 台股盤中重挫(加權約 −3.1%),PC/ODM(華碩 −4.7%、宏碁 −6.2%、緯創 −4.0%)與記憶體/載板(南亞科 −6.9%、南電 −7.2%)同步下跌(盤中快照,標題層級)。

### 2.4 Anthropic:不在本季損益,而在 OCI 與承諾

## 五、三家交叉解讀(推論)

### 5.1 AI 資本支出週的合併畫面(Alphabet、Microsoft、Amazon)
| | Alphabet(Q3) | Microsoft(FQ1) | Amazon(Q3) |
|---|---|---|---|
| 雲端營收成長 | Cloud +103% | Azure +48% | AWS +39% |
| backlog | Cloud $560.8B | 商業 RPO $677B(+73%) | AWS $578B |
| 單季 capex | $513.6 億 | 含租賃 $452 億 | 淨 $759 億(總 $773 億) |
| 單季 FCF | −$90.65 億 | 約 +$186 億 | **約 −$335 億(推算)** |
| 負債 | 長期債務 $1,251 億 | — | **長期債務 $1,731 億** |
| 股價反應 | −12.64% | −0.16% | 盤後約 −7% |
- **三大雲端 2026 capex 指引合計:Alphabet $195–205B、Amazon 約 $220B、Microsoft 約 $170B(口徑待核),加上 Meta $135–145B,粗估 $7,000 億以上。** **關鍵:需求端(backlog:Google $561B + AWS $578B + Microsoft $677B ≈ $1.8 兆)繼續上修,但市場開始用「FCF 與融資」而非「backlog」定價——這是 10/28–10/29 連續賣壓的共同主題。**
- **Amazon 與 Alphabet 的差別:** AWS 的營業利益率 38.7% 與 Cloud 36.2% 接近;但 Amazon 的 capex 對共識超出約 $186 億(32%)、Alphabet 低於共識約 $37 億;Amazon 的 TTM FCF −$424 億、Alphabet 的 TTM 仍 +$197.5 億——**Amazon 的現金缺口更大,卻只跌約 7%(Alphabet −12.64%),原因可能是 AWS 成長加速 + 營業利益率創高 + Jassy 對 2027–28 成長 >40% 的明確數字(推論)。**
- **Anthropic 同時是三家的「共同曝險」:** Amazon($110B AWS 承諾 + 約 $190B 帳面價值)、Alphabet(Cloud backlog 約 20% 可能來自 Anthropic〔推算〕、持股帳面 $1,282 億)、Microsoft($44.9B Azure 承諾);Anthropic 的 IPO 定價(約 11/9 當週路演、11/20 掛牌,IFR)因而是雲端 capex 敘事的下一個驗證點(見 `./Anthropic_IPO_上市前披露分析.md`)。

### 5.2 記憶體的贏家與輸家:SanDisk vs Intel/PC
| | SanDisk(贏家) | Intel(輸家之一) |
|---|---|---|
| 記憶體價格 | 小幅續漲,毛利率 85%、營業利益率 80% | 記憶體漲價推高系統價格、壓縮 PC 預算;**CFO:「not optimistic about next year in terms of memory」** |
| 終端 | **Consumer −29% QoQ**、手機/PC 單位 CY27 小幅下滑、資料中心 +61% | **客戶端 Q4 季減 >20%,2026 PC TAM −12%、2027 −10%** |
| 供給 | 位元成長中高十位數 %、受合資體限制 | **基板(EMIB)與 Intel 3 供給受限**,以色列廠停擺 |
| 長約 | NBM 約 50% FY27 位元已簽 | 多個客戶想簽 LTA(含 Oracle OCI) |
- **結論(推論):AI 把 NAND/DRAM、先進封裝、基板的供給吸走,資料中心與「AI 基礎設施供應鏈」賺走利潤,消費端(PC、手機)被排擠。** **Intel 本身是「兩面人」:DCAI +78%、營業利益率 41.5% 受惠 AI/agentic CPU 需求,CCPG 則被 PC 修正拖累,Foundry 虧損收窄但仍 −$18.5 億;市場把 Q4 指引(PC 弱 + 毛利率 38%)當成主要風險,而非 DCAI 的亮點。**
- **對 SanDisk 的反面意義:** Intel、Dell、HP 的盤後下跌(−7% 上下)說明終端需求疲弱;SanDisk 的 Consumer −29% 已先反映;**市場擔心 85% 毛利率是頂部——若 PC/手機需求破壞推升的是 NAND 價格上限,則 SanDisk 的利潤率對「價格」的敏感度遠大於對「位元」的敏感度。**

### 5.3 對台股的連結
1. **Amazon/Alphabet 的 capex 與 backlog 對台灣供應鏈是中長期利多(AI 伺服器、先進封裝、散熱電源、ASIC/TPU/Trainium 相關),但短期市場先砍「融資與現金流疑慮」:** 10/30 台股盤中重挫(加權約 −3.1%,盤中快照),不論 AI 基建或 PC 都一起跌。
2. **PC/ODM(華碩 −4.7%、宏碁 −6.2%、廣達 −3.3%、緯創 −4.0%、英業達 −4.2%)直接受 Intel Q4 指引與 PC TAM 下修衝擊;Intel 與 Dell/HP 的盤後 −7% 是同向訊號。**
3. **記憶體:** **SanDisk 持有南亞科約 3.9%(約 $10 億、折價 15%、鎖 3 年,並簽多年期 DRAM 供貨協議),本季因此認列 $5.13 億股權投資收益——南亞科股價下跌(10/30 −6.9% 盤中)將直接影響 SanDisk 的股權投資損益。**南亞科、華邦電、旺宏、群聯、威剛的 10/28 反彈在 10/29–10/30 被 Samsung 淨利不如預期、SanDisk 盤後翻跌、KOSPI/SK hynix 盤中重挫所壓回;**但 SK hynix/Samsung/Micron 的長約(涵蓋 2027–28 逾 50% 產能、2030 年前供給吃緊)與 SanDisk 的 NBM(約 50% FY27 位元)與「毛利率 85%」說明產業需求面仍強,下跌更像估值與周期頂部擔憂(推論)。**
4. **載板/PCB:** Intel 稱 EMIB 先進有機基板是「產業性短缺」、2027 下半年產能 +40%;Intel 18A/14A 與外部代工客戶將於兩季內有消息;台廠載板(欣興、南電、景碩)10/30 盤中 −4.8%~−7.2%,與 Intel 並未直接連動(陸行之的評論為 C 級)。
